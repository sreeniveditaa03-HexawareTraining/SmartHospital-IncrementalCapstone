# SmartHospital - Hospital Management System

## Project Overview

SmartHospital is a Hospital Management System developed using Python and Microsoft SQL Server. It aims to streamline hospital operations by managing patients, doctors, clinics, appointments, prescriptions and billing.

## Technology Stack

- Python
- Microsoft SQL Server
- SQL
- Git and GitHub

## Project Architecture

The project will follow a layered architecture consisting of:

- Entity Layer
- DAO Layer
- Service Layer
- Utility Layer
- Main Application

## Project Sprints

### Sprint 1 - Database
- Database creation
- Table design
- Primary and foreign key constraints
- Sample data insertion
- Database validation

### Sprint 2 - Object-Oriented Programming
- Entity classes
- Encapsulation
- Inheritance
- Polymorphism

### Sprint 3 - Advanced Programming
- Collections
- Interfaces and service abstraction
- Exception handling
- Concurrency

### Sprint 4 - Database Integration and Testing
- Python-SQL Server integration
- CRUD operations
- Unit testing
- Integration testing
